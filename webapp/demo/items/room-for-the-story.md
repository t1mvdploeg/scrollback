# Give the story room to breathe

## What is explained
- Build the page around a wide feature story and a narrow reading column.
- Use a 12-column grid, a 720px text measure and a 1.5 line height.
- The video shows both desktop and mobile layouts, including how the image moves above the headline.

## Tools, repos and links mentioned
- CSS Grid: The layout uses named areas for the title, image and story. (on screen)

## Design
- Colours: Warm paper #F5F1E9, ink #232721 and muted olive #7C8164; light mode.
- Type: Large, high-contrast serif headings paired with a plain sans for captions; the fonts are not named.
- Layout: Asymmetric editorial hero, a fine rule and a comfortably narrow reading column.
- Effects: A short fade on images; no scroll-driven movement.
- Looks like: Editorial magazine
- Libraries: CSS Grid (on screen)

## Core claim
A clear reading hierarchy can make a small journal feel as considered as a print publication.

## Usefulness
The measurements and mobile example make this easy to adapt. The font names are missing, but the hierarchy is clear enough to recreate with another pair. No product promotion is visible; the example itself is the useful part.
