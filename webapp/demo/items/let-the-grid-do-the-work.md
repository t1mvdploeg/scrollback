# Let the grid do the responsive work

## What is explained
- The example uses repeat, minmax and a capped content width to make a story index wrap.
- The featured story spans two columns only when enough space is available.
- A visible media query returns every story to one column on narrow screens.

## Tools, repos and links mentioned
- CSS Grid: The complete grid declaration is visible in the editor. (on screen)

## Design
- Colours: Warm paper #F5F1E9, dark ink #232721 and olive #7C8164; light mode.
- Type: Serif story headlines with a small sans metadata line.
- Layout: Fluid editorial story grid, one larger feature and a shared baseline for metadata.
- Effects: No animation; the demonstration changes only the viewport width.
- Looks like: Editorial magazine
- Libraries: CSS Grid (on screen)

## Core claim
A few well-chosen grid rules can replace a collection of fragile breakpoint fixes.

## Usefulness
The exact declarations and the narrow-screen example are visible. It does not cover unusually long titles or translated copy, so those still need testing. CSS Grid is already in the fictional profile; the value is in using it more deliberately.
