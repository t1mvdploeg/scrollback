# One shortcut, less capture friction

## What is explained
- A visible shortcut accepts a shared URL and prompts for a short “why I saved this” note.
- It creates a plain text entry containing title, source and context.
- The demonstration shows a second entry being appended without replacing the first.

## Tools, repos and links mentioned
- Nook Shortcuts: A fictional capture shortcut listed in the demo profile. (on screen)

## Core claim
Writing why you saved a link makes it easier to use later.

## Usefulness
The capture fields and append behavior are shown clearly. Duplicate handling and failed network requests are not covered. The fictional profile already includes this shortcut, so the recommendation is to use the context field more consistently.
