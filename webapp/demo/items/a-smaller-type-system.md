# Make four type sizes do more

## What is explained
- Use four roles: display, heading, body and label.
- The visible CSS sets the body at 17px and the label at 12px, with a fluid display size.
- Keep the body measure between 60 and 70 characters and increase spacing before adding another size.

## Tools, repos and links mentioned
- CSS Grid: A visible grid example keeps the type specimens aligned. (on screen)

## Design
- Colours: Off-white #F5F1E9, ink #232721 and one blue accent #567AAB; light mode.
- Type: A serif display face with a neutral sans; only four named size roles.
- Layout: An editorial cover and two-column index with aligned baselines and broad margins.
- Effects: None; all six slides show static examples.
- Looks like: Editorial magazine
- Libraries: CSS Grid (on screen)

## Core claim
A smaller type system is easier to keep consistent than a collection of one-off sizes.

## Usefulness
The size roles and CSS are visible and specific. This is a useful design exercise rather than evidence that four sizes suit every product. The slides show no sponsorship, and the underlying grid is already listed in the fictional profile.
